# Ludus

Uma rede social para quem gosta de videogames.

## Stack

- Vite + JavaScript (ES modules)
- Supabase (PostgreSQL, Auth, Storage e Edge Functions)
- GitHub Pages
- SteamGridDB API (por meio de função server-side)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Variáveis de ambiente

Crie um arquivo `.env.local` com as variáveis documentadas em `.env.example`. Nunca publique chaves secretas.
